| Podman sandbox | PASS | Linux VM / Podman 4.9.3 rootful；与 Docker 相同的真实隔离矩阵通过 |
| Bubblewrap sandbox | PASS | Linux VM / bubblewrap 0.9.0 rootful；mount/network namespace、只读根、workspace、timeout 通过 |
| Remote sandbox | CONTRACT PASS | create/exec/spawn/pause/resume/snapshot/restore/fork/terminate；`hosted_provider=false` |

边界说明：临时 PostgreSQL 使用本机 trust/明文 loopback，证明 store 的真实 SQL、索引和
跨进程语义，不代表生产 TLS/最小权限配置已验收；临时 MinIO 使用 loopback HTTP，验证了
对象 SSE，但生产 bucket policy/TLS 仍由部署方负责。Podman/Bubblewrap 在嵌套 VM 的普通
用户下分别受 cgroup delegation 与 network namespace capability 限制，均 fail closed；
功能矩阵在 rootful Linux backend 完成。Remote 只证明 Cody 自带 adapter contract，项目
没有内置托管 provider，因此不宣称远端服务 E2E。

Standalone binary 已在 GitHub 原生 Linux、macOS、Windows runner 全部构建成功；本地
进一步实际启动并请求 `/health` 的是 macOS arm64 产物。手动验证在非 tag ref 上运行，
`release` job 按安全条件跳过，没有创建 GitHub Release 或发布 PyPI。
